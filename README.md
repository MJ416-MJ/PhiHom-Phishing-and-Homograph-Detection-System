# PhiHom
A desktop-based phishing detection tool for real-time link verification in digital communications
## Data Setup
If you have your own set of legitimate domains list and you arent sure if all the websites are legitimate e.g those containing numerical numbers and shorteners
Run `cleaner.py` from the `backend/` directory to generate 
`legitimate_clean_doms.csv` before starting the system.
## Note
Your file must be called legitimate_domains.csv for the code to work
Alternatively, just change the file name
