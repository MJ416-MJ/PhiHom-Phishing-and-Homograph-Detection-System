# Phihom — Phishing and Homograph Detection System

Phihom is a desktop-based phishing detection tool designed to help users assess suspicious URLs and identify links that imitate legitimate websites.

## Overview

Phihom focuses on identifying potentially deceptive URLs, including homograph and character-substitution attacks. It provides URL risk assessments with explanations to help users understand why a link may be flagged and, where possible, suggests the likely legitimate website.

## Key Features

- Detection of homograph and character-substitution attacks.
- Rule-based URL risk assessment.
- Explainable results to help users understand suspicious URL indicators.
- Suggestions for the likely legitimate website when an imitation is detected.

## Technology and Development

Phihom is an ongoing software project. Further enhancements may include exploring AI-assisted detection capabilities.
